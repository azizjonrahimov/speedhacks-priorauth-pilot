# RESEARCH.md — decisions from the 30-min research pass (Oct 11 2026)

1. **Dial SDK (`@getdial/sdk` 0.41):** `new DialClient({apiKey})`; `dial.makeCall({to, fromNumberId, outboundInstruction, language, idempotencyKey?})` returns `{id, status}` immediately (Queued); `dial.getCall(id)` → `transcript` (flat) + `transcriptTurns[{speaker: "agent"|"user"|"transfer_target", text, startMs, endMs}]`; `dial.sendMessage({to, fromNumberId, body})`; `dial.listNumbers()`. Decision: wait for `call.ended` (exactly one per call, carries terminal status) AND `call.transcribed` (thin, `data.callId`); whichever lands last with a transcript wins.
2. **Dial events:** `conn = await dial.newEventsConnection(); for await (const ev of conn)`; envelope `{id, object, type, version, createdAt, relatedObject, data}`. Stream is presence-based (replay only within 2 min). Decision: own reconnect loop with backoff plus a 20 s `getCall()` poll as a safety net for the pending call.
3. **Dial limits:** free account = 5 min/call, 2 concurrent; `maxCallDurationSeconds` > 300 returns 400 on free; we keep 240. No sandbox, every call is real. Placing a call is NOT idempotent unless `idempotencyKey` is sent (SDK supports it; CLI has `--idempotency-key`). Decision: always send `${caseId}:gapfill:${attempt}`.
4. **Dial SMS:** `sendMessage` not idempotent; US SMS to arbitrary phones blocked without 10DLC; works Dial-number→Dial-number. Decision: `PATIENT_PHONE` must be a second Dial number, else `channel: "simulated"`.
5. **Dial CLI:** `dial doctor`, `dial number list --json`, `dial number purchase --area-code 415 --explicit-programmatic-consent "..."`. CLI not installed on this box at research time.
6. **Da Vinci PAS STU2.1 request bundle:** `Bundle.type=collection`, `meta.profile=.../profile-pas-request-bundle`, first entry = Claim (`profile-claim`), then Organization (requestor `profile-requestor`, insurer `profile-insurer`), Coverage (`profile-coverage`), Patient (`profile-subscriber`). Claim: `status=active, type=professional, use=preauthorization, priority=normal, insurance[{sequence:1,focal:true,coverage}], item[{sequence, extension[serviceItemRequestType=IN, certificationType=I], category=1, productOrService=CPT, servicedDate, locationCodeableConcept=11}]`. Identifier system = PATIENT_EVENT_TRACE_NUMBER.
7. **Reference server (github HL7-DaVinci/prior-auth):** `POST /fhir/Claim/$submit` with the bundle; 201 + Location on success; OperationOutcome on error. Its own test bundle puts Claim first then Patient/Practitioner/Coverage/Condition/Observation; `preAuthRef` carries the auth number; `disposition: "Granted"`. README says OAuth client_credentials is required in prod mode; live server returns 400 on empty bundle (per plan). Decision: time-box 40 min, expect auth or profile rejection, keep `PAYER_ADAPTER=mock` as default.
8. **Adjudication codes (X12 278 HCR01):** A1 Certified in total (approved), A2 Certified partial, A3 Not certified (denied), A4 Pended, A6 Modified, C Cancelled, CT Contact payer. Mock adapter emits A1/A3/A4.
9. **CMS-0057-F:** 72 h expedited / 7 calendar days standard decisions from Jan 1 2026; specific denial reason required from 2026; PAS API due Jan 1 2027; metrics posted by Mar 31 2026. Decision: mock payer returns a specific denial reason string; red-flag cases set `expedited=true` and show a 72 h SLA.
10. **Aetna CPB 0236 (spine MRI):** radiculopathy = pain + objective motor/reflex change in a nerve-root distribution AND no improvement after **6 weeks** of conservative therapy (activity, analgesics, NSAIDs, muscle relaxants); 4 weeks for spondylolisthesis/degenerative; stand-alone criteria (no trial needed): suspected cauda equina / cord compression, rapidly progressive neuro deficit or major motor weakness, suspected infection, tumor/metastasis, trauma fracture.
11. **Aetna CPB 0171 (extremity MRI, rev 03/31/2026):** knee MRI covered for persistent pain/swelling/instability not responding to **≥3 weeks** conservative therapy (rest, ice, compression, elevation) when not injury-related; injury-related requires multi-view x-rays ruling out fracture/loose body; true locking; suspected osteomyelitis; tumor.
12. **Aetna CPB 0004 (OSA):** attended in-lab PSG (95810) when symptoms suggestive of OSA plus a comorbidity that degrades home testing: COPD/asthma with nocturnal O2 or hypercapnia, neuromuscular disease, CHF (NYHA III/IV or LVEF<45%), stroke, epilepsy, chronic opioids, pulmonary HTN, **super obesity BMI > 45**, or negative/inadequate home test. Symptom bundle: excessive daytime sleepiness + ≥2 of loud snoring / witnessed apneas / hypertension.
13. **Aetna CPB 0325 (PT):** written plan of care with objective measures; reasonable expectation of significant improvement; skilled need (licensed therapist); not maintenance (plateau = 4 weeks); functional loss documented.
14. **Cigna CNF 684 (GLP-1 weight loss, Wegovy):** PDF 404'd on all three Cigna static hosts today; criteria taken from Cigna's published summaries (SingleCare/D3rx cite IP0206 wording): age ≥18; BMI ≥30, or ≥27 with ≥1 weight-related comorbidity (HTN, dyslipidemia, T2DM, OSA, CVD); ≥**3 months** documented diet/behavioral program; used with lifestyle modification; not combined with another weight-loss drug. Flagged as secondary-sourced in rules.json.
15. **BCBS SC CAM 717 (CT abdomen, rev 02/18/2026):** CT abd/pelvis 74177 is the right code when the process spans both; RUQ pain for suspected biliary disease requires **negative or equivocal ultrasound** first; jaundice / abnormal LFTs after equivocal ultrasound; pancreatitis = epigastric pain + elevated lipase, imaging if no improvement after 72 h and US non-diagnostic; supporting docs must include recent office notes and lab data. Ultrasound may be skipped if body habitus limits it.
16. **Anthropic:** `@anthropic-ai/sdk` 0.133; forced structured output = `tools:[{name, input_schema, strict:true}]` + `tool_choice:{type:"tool", name}`, read `content.find(b=>b.type==="tool_use").input`. Model from `ANTHROPIC_MODEL` env, default `claude-sonnet-5-5` (plan said sonnet-4-5, which is retired). zod 4 has native `z.toJSONSchema()` so `zod-to-json-schema` was dropped.
18. **Live Da Vinci result (12:40 PT):** first attempt returned `400 OperationOutcome "Unknown resource type http:"` because the server resolves `Reference.reference` as `ResourceType/id` and chokes on absolute URLs. Switched all references to relative (`Patient/<id>`) while keeping absolute `fullUrl`s → `201 Created`, response is a `profile-pas-response-bundle` with a `ClaimResponse` (`outcome: queued`, `disposition: Pending`, `preAuthRef` = server id, our PATIENT_EVENT_TRACE_NUMBER echoed). So `PAYER_ADAPTER=davinci` works live and lands as **pended (A4)**; the mock adapter is used for the approved/denied branches and chaos.
19. **Keewano (optional, 12:58 PT):** `@keewano/node-sdk` needs a project API key, a persistent `dataDir`, and codegen'd per-user batch reporters; no token on hand and it is cut-list item 2 in the plan, so skipped. The ledger's `events` table (case_id, seq, type, payload, at, actor) already maps 1:1 to an event-DB ingest if added later.
17. **Toolchain:** machine had no Node; installed Node 24.20 LTS via winget (plan said 22; 24 is the current LTS and has better-sqlite3 prebuilds). Dial CLI not installed; Dial calls need `DIAL_API_KEY` + `DIAL_FROM_NUMBER_ID` in `.env`.
