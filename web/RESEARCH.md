# Frontend research decisions (SpeedHacks, 2026-10-11, ~12:00 PT)

1. **Component kit: shadcn/ui on Radix** (`npx shadcn init -b radix -p nova`). The current CLI (Oct 2026) replaced `--base-color` with `-b radix|base|aria` and presets; "nova" = Lucide icons + Geist. Copy-in components mean we can restyle criteria rows / call card freely. Source: https://ui.shadcn.com/docs/installation/vite
2. **Styling: Tailwind CSS v4** via `@tailwindcss/vite` and `@import "tailwindcss"`; theme tokens live in `src/index.css` under `@theme inline` (no tailwind.config). Source: https://tailwindcss.com/docs/installation/using-vite
3. **Theme: "calm clinical console"** — hand-tuned oklch tokens instead of a tweakcn export (site is JS-only, couldn't fetch presets): primary teal (#0F766E ≈ oklch(0.51 0.09 183)), slate neutrals, 8px radius, 1px borders. Semantic: met=emerald, missing=rose, unclear=amber, expedite=red stripe. Light default, `.dark` class toggle kept.
4. **Fonts: Geist Variable** (shipped by the shadcn preset via @fontsource, so no Google Fonts network dependency during the recording) + `font-variant-numeric: tabular-nums` on every timer/KPI. Base font 15px, demo mode bumps to 17px.
5. **Icons: lucide-react** — Stethoscope, FileCheck, PhoneCall, ShieldCheck, Clock, AlertTriangle, Send, Siren.
6. **Charts: Recharts v3 wrapped by shadcn `chart`** (ChartContainer/ChartTooltipContent). Recharts v3 wants `var(--chart-1)` not `hsl(var(--chart-1))`. Source: https://ui.shadcn.com/docs/components/chart
7. **Motion: `motion` package, import from `motion/react`** (ex-Framer Motion). `layout` + `AnimatePresence` for criteria rows flipping missing→met; `useSpring`/`useMotionValue` for the KPI number ticker (Magic UI NumberTicker pattern re-implemented locally). Source: https://motion.dev/docs/react
8. **Data: @tanstack/react-query** for fetch/cache; one `EventSource(VITE_API_URL + '/stream')` hook that invalidates queries on any event (debounced 300 ms) and tolerates unknown event types. Mock layer = fetch shim in `src/mock/` keyed by `VITE_USE_MOCK=1`, with a scripted fake case that walks through every state.
9. **Design references** (studied, not copied): Linear for list density (compact 40px rows, muted secondary text), Vercel for KPI tiles (big tabular number, small delta line), Cohere Health marketing (headline metrics: % real-time approvals, "humans in control" footnote → we show staff-review time and keep a human "Mark review complete" step), Tennr (status visibility / control-tower framing, HIPAA badge trust cues). Neither vendor exposes product UI publicly.
10. **Accessibility / demo legibility**: WCAG AA contrast on all chips (text on 100-tint backgrounds with 800-tint text), base 15–16px type, focus rings kept, no gradients except the case header stripe.
